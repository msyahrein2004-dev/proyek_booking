# KINGZ SOT Package

This package contains the product source-of-truth documents and the initial coding-agent contract for the KINGZ Barber Shop Booking System.

## Files
- `PRD.md` — product requirements, roles, MVP scope, business rules, and acceptance criteria.
- `UI-GUIDELINE.md` — brand tokens, visual system, component behavior, responsive rules, and accessibility guidance.
- `IMPLEMENTATION_PLAN.md` — React + Vite structure, route map, milestones, mock data model, and QA checklist.
- `AGENTS.md` — execution contract and scope guardrails for coding agents.
- `EXECUTION_PROMPT.md` — prompt to begin the initial frontend implementation.

## Project constraints
- Frontend: React + Vite.
- Backend and database: not selected.
- Until they are selected, implementation should use clearly labeled mock data and mock operations.
- The SOT documents govern scope. Do not add features without owner approval.

## Suggested repository placement
Copy the three SOT files into `docs/` in the app repository:
- `docs/PRD.md`
- `docs/UI-GUIDELINE.md`
- `docs/IMPLEMENTATION_PLAN.md`

Keep `AGENTS.md` and `EXECUTION_PROMPT.md` at the repository root.
